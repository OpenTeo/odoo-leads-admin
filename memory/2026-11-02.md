## Leçon

La session hébergée sur le cloud ne peut pas atteindre `odoo-leads-admin.vercel.app` par politique réseau. Il faudrait soit :
1. Mettre à jour la politique réseau pour autoriser ce domaine
2. Ou ajouter un fallback fichier dans `lib/dashboard-data.mjs` pour lire depuis `snapshot/`
